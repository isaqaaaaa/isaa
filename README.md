# isaa — локальный генератор промптов

Сервер принимает идею ролика и через Anthropic API возвращает английский кинематографический промпт для Omniflash (по умолчанию) или Google Flow (`target: "flow"`). Можно описывать математические мультфильмы и YouTube Shorts на русском. Приложение пока создаёт текст промпта, а не видео; веб-интерфейса нет.

## 1. Установите Node.js на Windows

1. Откройте [официальную страницу Node.js](https://nodejs.org/en/download).
2. Выберите версию **24 LTS**, Windows и установщик `.msi` для архитектуры своего компьютера (обычно x64).
3. Установите с обычными настройками, включая npm и добавление в PATH.
4. Закройте и заново откройте PowerShell, проверьте:

```powershell
node --version
npm --version
```

Если PowerShell запрещает запуск `npm.ps1`, используйте `npm.cmd` вместо `npm` во всех командах ниже (например, `npm.cmd ci` и `npm.cmd start`). Менять политику выполнения скриптов не требуется.

## 2. Скачайте проект и зависимости

На [странице репозитория](https://github.com/isaqaaaaa/isaa) нажмите **Code → Download ZIP**. Распакуйте архив. Откройте PowerShell в распакованной папке, где находятся `package.json` и `index.js` (в Проводнике можно ввести `powershell` в адресную строку).

Если Git уже установлен, вместо ZIP можно выполнить:

```powershell
git clone https://github.com/isaqaaaaa/isaa.git
cd isaa
```

Установите зафиксированные в `package-lock.json` зависимости:

```powershell
npm ci
```

Нужен доступ к интернету. Дождитесь успешного окончания команды. Выполняйте дальнейшие команды из этой же папки.

## 3. Создайте .env и добавьте ключ

При первой настройке выполните:

```powershell
if (-not (Test-Path .env)) {
    Copy-Item .env.example .env
}
notepad .env
```

В файле находятся:

```dotenv
PORT=3000
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

Для настоящей генерации создайте свой ключ в [Claude Console](https://platform.claude.com/settings/keys) и замените только `your_anthropic_api_key_here` в локальном `.env`. Сохраните файл именно как `.env`, а не `.env.txt`. Ключ передаётся серверу из этого файла; в запрос PowerShell его добавлять не нужно.

Не вставляйте настоящий ключ в исходники, `.env.example`, README, чат или скриншоты. Файлы `.env` и `.env.*` исключены из Git, кроме шаблона `.env.example`. Если ключ уже опубликован, отзовите его в Console и создайте новый: добавление в `.gitignore` не удаляет старый ключ из истории Git.

Для проверки запуска и некорректных запросов оставьте значение-заглушку из шаблона: настоящий ключ не нужен. Успешная генерация требует действующего ключа, доступа к модели и доступного лимита API.

## 4. Запустите сервер

```powershell
npm start
```

Ожидаемое сообщение после загрузки настроек:

```text
Server listening at http://127.0.0.1:3000
```

Оставьте это окно открытым. Адрес сервера: `http://127.0.0.1:3000`. Для остановки нажмите **Ctrl+C**. После изменения `.env` остановите и запустите сервер заново.

Сервер явно слушает только `127.0.0.1` — локальный IPv4-адрес этого компьютера (localhost). Прямые подключения с других устройств по сети не принимаются. Это важно, потому что `/generate-prompt` использует ваш ключ Anthropic и не требует авторизации: доступ к серверу может приводить к платным API-запросам. Привязка к localhost ограничивает сетевой доступ, но не запрещает обращения от программ на вашем компьютере. Порт по умолчанию — `3000`; настройка `PORT` меняет только порт, а адрес остаётся `127.0.0.1`.

Сейчас открытие адреса в браузере покажет `Cannot GET /`: страница и маршрут `GET /` ещё не реализованы. Для работы используйте `POST /generate-prompt`. После добавления веб-интерфейса на этом сервере запускайте приложение той же командой `npm start` и открывайте **http://127.0.0.1:3000** в браузере на том же компьютере. Если изменили `PORT`, замените `3000` на выбранный порт. Числовой адрес позволяет избежать разрешения имени `localhost` в IPv6-адрес `::1`.

## 5. Отправьте математическую тему из PowerShell

Откройте **второе окно PowerShell**. Следующий запрос вызывает Anthropic и предназначен для настройки с настоящим ключом:

```powershell
$body = @{
    rawText = "Миа и Гус объясняют, почему минус на минус даёт плюс. Короткий рисованный математический мультфильм с движущимися числами."
} | ConvertTo-Json -Compress

$response = Invoke-RestMethod -Uri "http://127.0.0.1:3000/generate-prompt" -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
$response.prompt
```

Явное преобразование в UTF-8 сохраняет кириллицу, в том числе в Windows PowerShell 5.1.

При успешной генерации сервер возвращает **HTTP 200** и JSON такого формата:

```json
{
  "prompt": "Mia and Gus stand beside a playful animated number line..."
}
```

Это иллюстрация формата, а не результат проверенного обращения к API. Текст каждый раз может отличаться; по текущей настройке генератора он будет на английском.

## Режим Google Flow: один рисованный математический ролик

В существующий `POST /generate-prompt` можно передать необязательное поле `target`:

| Значение | Результат |
| --- | --- |
| Поле отсутствует или `"omniflash"` | Прежний английский кинематографический абзац для Omniflash. |
| `"flow"` | Подробный английский промпт для одного короткого рисованного 2D-ролика: около 8 секунд, вертикальный формат 9:16, движение героев и математически корректная визуализация. |
| Любое другое значение, включая `null` и пустую строку | HTTP 400 до обращения к Anthropic. Значения чувствительны к регистру. |

Это один готовый промпт, а не отдельный режим раскадровки. Формат ответа не меняется: `{ "prompt": "..." }`.

Пример темы **«Почему минус на минус даёт плюс»** (нужен работающий сервер и настоящий Anthropic API-ключ):

```powershell
$body = @{
    rawText = "Миа и Гус объясняют, почему минус на минус даёт плюс. Покажи на числовой прямой: умножение -2 на -1 разворачивает стрелку от нуля к -2, и она указывает на +2. Один короткий рисованный математический ролик."
    target = "flow"
} | ConvertTo-Json -Compress

$response = Invoke-RestMethod -Uri "http://127.0.0.1:3000/generate-prompt" -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
$response.prompt
$response.prompt | Set-Clipboard
```

Как перенести результат:

1. Откройте [Google Flow](https://flow.google/) и создайте или откройте проект.
2. Выберите генерацию **Video** из текстового описания. Вставьте содержимое `$response.prompt` из буфера в поле промпта — только английский текст, без JSON и команды PowerShell.
3. В параметрах генерации выберите вертикальный формат **9:16**, один результат и длительность около **8 секунд**, если она доступна для выбранной модели. Упоминание формата в тексте не заменяет настройку формата в интерфейсе.
4. Если используете изображения Мии и Гуса, добавьте их как референсы доступным в вашей версии способом. Генератор isaa не загружает эти изображения и не знает внешность героев: нужные детали можно описать в `rawText`.
5. Запустите генерацию. Проверьте направление стрелки, знаки и итог. При ошибке чисел или надписей поправьте промпт или добавьте точную формулу при монтаже. Системная инструкция просит математически корректный результат, но не гарантирует точность генерации.

Ориентир по интерфейсу: [официальная справка Google Flow](https://support.google.com/flow/answer/16353334?co=GENIE.Platform%3DDesktop&hl=en). Доступные настройки зависят от модели. Приложение isaa создаёт только текст через Claude и не отправляет его в Flow автоматически.

## 6. Проверьте некорректный запрос без настоящего ключа

Запустите сервер с `.env` из шаблона (со значением-заглушкой) и отправьте во втором окне:

```powershell
try {
    Invoke-RestMethod -Uri "http://127.0.0.1:3000/generate-prompt" -Method Post -ContentType "application/json" -Body "{}" -ErrorAction Stop
    throw "Проверка не пройдена: ожидался HTTP 400."
} catch {
    if ($null -eq $_.Exception.Response) { throw }
    $status = [int]$_.Exception.Response.StatusCode
    if ($status -ne 400) { throw }
    Write-Host "Проверка пройдена: HTTP $status"
    Write-Host $_.ErrorDetails.Message
}
```

Ожидается **HTTP 400** с телом:

```json
{
  "error": "Missing or invalid \"rawText\" in request body."
}
```

Такой запрос отклоняется до обращения к Anthropic. Аналогично можно проверить `-Body '{"rawText":""}'`, `-Body '{"rawText":"   "}'` и `-Body '{"rawText":123}'`. Пустой объект `{}` — корректный JSON с отсутствующим обязательным полем; отправляйте именно его, а не запрос без тела.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| `node` или `npm` не найдены | Переоткройте PowerShell после установки Node.js. |
| Запрещён `npm.ps1` | Используйте `npm.cmd ci` и `npm.cmd start`. |
| Не найден `package.json` | Перейдите в папку проекта, содержащую этот файл. |
| `ERR_MODULE_NOT_FOUND` | Убедитесь, что `npm ci` завершилась успешно. |
| `npm ci` возвращает сетевую ошибку или 403 | Проверьте доступ к npm registry и ограничения сети. |
| `EADDRINUSE` | Остановите другой экземпляр или задайте `PORT=3001` в `.env`, перезапустите сервер и замените порт в запросах. |
| HTTP 400 | Передайте JSON с непустой строкой `rawText`; `target` должен отсутствовать либо равняться `"omniflash"` или `"flow"`. |
| HTTP 500 при генерации | Проверьте ключ, доступ к API и модели; ошибка содержит поля `error` и `details`. Не публикуйте полный журнал без проверки на секреты. |
| HTTP 504 | В текущей обработке сервер сообщает о тайм-ауте Anthropic; повторите запрос позже. |

В `claudeService.js` сейчас указана модель `claude-3-haiku-20240307`. Успешность реальной генерации зависит и от её доступности в API; команда запуска не меняет модель или логику генерации.

## Автоматические проверки без ключа

```powershell
npm test
```

Тесты используют встроенный `node:test` (Node.js 24 из инструкции выше), подставной клиент Anthropic и объекты запроса/ответа обработчика. Настоящий ключ, `.env`, интернет и установка дополнительных тестовых библиотек не требуются. Проверяются параметры запросов обоих режимов, сохранение исходной инструкции Omniflash, валидация входных данных, HTTP-статусы обработчика 200/400/500/504, пустые и обрезанные ответы, ошибки API и тайм-ауты. Клиент Anthropic загружается только при настоящей генерации.

Дополнительно `network.test.js` запускает настоящий `index.js` в отдельном процессе, подменяя Express и dotenv через встроенные модульные хуки Node.js 24. Подставной Express передаёт аргументы прослушивания настоящему TCP-серверу Node.js: проверяются адрес `127.0.0.1` и семейство IPv4. Тест проверяет порт по умолчанию `3000` и пользовательский `PORT=3001`, а для открытия сокета использует свободный временный порт, чтобы не конфликтовать с запущенным приложением. Локальный `.env` не читается, ключ очищается, импорт Anthropic SDK запрещён. Это проверка сетевой конфигурации запуска, а не интеграционный HTTP-тест Express.
