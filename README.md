# isaa — локальный генератор промптов

Сервер принимает идею ролика и через Anthropic API возвращает английский кинематографический промпт для Omniflash. Можно описывать математические мультфильмы и YouTube Shorts на русском. Приложение пока создаёт текст промпта, а не видео; веб-интерфейса нет.

## 1. Установите Node.js на Windows

1. Откройте [официальную страницу Node.js](https://nodejs.org/en/download).
2. Выберите версию **24 LTS**, Windows и установщик `.msi` для архитектуры своего компьютера (обычно x64).
3. Установите с обычными настройками, включая npm и добавление в PATH.
4. Закройте и заново откройте PowerShell, проверьте:

```powershell
node --version
npm --version
```

Если PowerShell запрещает запуск `npm.ps1`, используйте `npm.cmd` вместо `npm` во всех командах ниже (например, `npm.cmd ci` и `npm.cmd start`). Менять политику выполнения скриптов не требуется.

## 2. Скачайте проект и зависимости

На [странице репозитория](https://github.com/isaqaaaaa/isaa) нажмите **Code → Download ZIP**. Распакуйте архив. Откройте PowerShell в распакованной папке, где находятся `package.json` и `index.js` (в Проводнике можно ввести `powershell` в адресную строку).

Если Git уже установлен, вместо ZIP можно выполнить:

```powershell
git clone https://github.com/isaqaaaaa/isaa.git
cd isaa
```

Установите зафиксированные в `package-lock.json` зависимости:

```powershell
npm ci
```

Нужен доступ к интернету. Дождитесь успешного окончания команды. Выполняйте дальнейшие команды из этой же папки.

## 3. Создайте .env и добавьте ключ

При первой настройке выполните:

```powershell
if (-not (Test-Path .env)) {
    Copy-Item .env.example .env
}
notepad .env
```

В файле находятся:

```dotenv
PORT=3000
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

Для настоящей генерации создайте свой ключ в [Claude Console](https://platform.claude.com/settings/keys) и замените только `your_anthropic_api_key_here` в локальном `.env`. Сохраните файл именно как `.env`, а не `.env.txt`. Ключ передаётся серверу из этого файла; в запрос PowerShell его добавлять не нужно.

Не вставляйте настоящий ключ в исходники, `.env.example`, README, чат или скриншоты. Файлы `.env` и `.env.*` исключены из Git, кроме шаблона `.env.example`. Если ключ уже опубликован, отзовите его в Console и создайте новый: добавление в `.gitignore` не удаляет старый ключ из истории Git.

Для проверки запуска и некорректных запросов оставьте значение-заглушку из шаблона: настоящий ключ не нужен. Успешная генерация требует действующего ключа, доступа к модели и доступного лимита API.

## 4. Запустите сервер

```powershell
npm start
```

Ожидаемое сообщение после загрузки настроек:

```text
Server listening on port 3000
```

Оставьте это окно открытым. Адрес сервера: `http://localhost:3000`. Для остановки нажмите **Ctrl+C**. После изменения `.env` остановите и запустите сервер заново.

Открытие адреса в браузере может показать `Cannot GET /`: страница и маршрут `GET /` не реализованы. Для работы используйте `POST /generate-prompt`.

## 5. Отправьте математическую тему из PowerShell

Откройте **второе окно PowerShell**. Следующий запрос вызывает Anthropic и предназначен для настройки с настоящим ключом:

```powershell
$body = @{
    rawText = "Миа и Гус объясняют, почему минус на минус даёт плюс. Короткий рисованный математический мультфильм с движущимися числами."
} | ConvertTo-Json -Compress

$response = Invoke-RestMethod -Uri "http://localhost:3000/generate-prompt" -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
$response.prompt
```

Явное преобразование в UTF-8 сохраняет кириллицу, в том числе в Windows PowerShell 5.1.

При успешной генерации сервер возвращает **HTTP 200** и JSON такого формата:

```json
{
  "prompt": "Mia and Gus stand beside a playful animated number line..."
}
```

Это иллюстрация формата, а не результат проверенного обращения к API. Текст каждый раз может отличаться; по текущей настройке генератора он будет на английском.

## 6. Проверьте некорректный запрос без настоящего ключа

Запустите сервер с `.env` из шаблона (со значением-заглушкой) и отправьте во втором окне:

```powershell
try {
    Invoke-RestMethod -Uri "http://localhost:3000/generate-prompt" -Method Post -ContentType "application/json" -Body "{}" -ErrorAction Stop
    throw "Проверка не пройдена: ожидался HTTP 400."
} catch {
    if ($null -eq $_.Exception.Response) { throw }
    $status = [int]$_.Exception.Response.StatusCode
    if ($status -ne 400) { throw }
    Write-Host "Проверка пройдена: HTTP $status"
    Write-Host $_.ErrorDetails.Message
}
```

Ожидается **HTTP 400** с телом:

```json
{
  "error": "Missing or invalid \"rawText\" in request body."
}
```

Такой запрос отклоняется до обращения к Anthropic. Аналогично можно проверить `-Body '{"rawText":""}'`, `-Body '{"rawText":"   "}'` и `-Body '{"rawText":123}'`. Пустой объект `{}` — корректный JSON с отсутствующим обязательным полем; отправляйте именно его, а не запрос без тела.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| `node` или `npm` не найдены | Переоткройте PowerShell после установки Node.js. |
| Запрещён `npm.ps1` | Используйте `npm.cmd ci` и `npm.cmd start`. |
| Не найден `package.json` | Перейдите в папку проекта, содержащую этот файл. |
| `ERR_MODULE_NOT_FOUND` | Убедитесь, что `npm ci` завершилась успешно. |
| `npm ci` возвращает сетевую ошибку или 403 | Проверьте доступ к npm registry и ограничения сети. |
| `EADDRINUSE` | Остановите другой экземпляр или задайте `PORT=3001` в `.env`, перезапустите сервер и замените порт в запросах. |
| HTTP 400 | Передайте JSON с непустой строкой `rawText`. |
| HTTP 500 при генерации | Проверьте ключ, доступ к API и модели; ошибка содержит поля `error` и `details`. Не публикуйте полный журнал без проверки на секреты. |
| HTTP 504 | В текущей обработке сервер сообщает о тайм-ауте Anthropic; повторите запрос позже. |

В `claudeService.js` сейчас указана модель `claude-3-haiku-20240307`. Успешность реальной генерации зависит и от её доступности в API; команда запуска не меняет модель или логику генерации.

Команда `npm test` пока является исходной заглушкой и завершается ошибкой `Error: no test specified`. Для проверки запуска используйте шаги 4 и 6.

## Статус проверки изменений

При подготовке инструкции синтаксис `index.js` и `claudeService.js` проверен командой `node --check` на Node.js 24.19.0. Команда `npm start` вызывает `node index.js`.

Полная установка зависимостей в среде подготовки заблокирована ответом HTTP 403 от npm registry; офлайн-кэш также неполон. Поэтому фактический запуск HTTP-сервера и ответы на запросы в этой среде **не подтверждены**. Выше приведены ожидаемые ответы по существующему коду и команды для воспроизведения проверки на Windows. Настоящий API-ключ не использовался, реальная генерация не проверялась.
